# real-fireworks

夜空の打ち上げ花火を、メートル単位で見る単一ページです。`index.html` をブラウザで開くと動きます。

視点は打ち上げ地点から 500m、目の高さ 1.6m です。画面を上下に動かすと視線が変わり、自動の打ち上げは止められます。止めたあいだは種類を選んで、自分で打ち上げられます。

音は OpenGameArt の CC0 音源（rubberduck の "25 CC0 bang / firework SFX"）です。ページが再生するのは `sounds-data.js` に埋め込んだ WAV で、元の ogg は `sounds/` に置いてあります。
